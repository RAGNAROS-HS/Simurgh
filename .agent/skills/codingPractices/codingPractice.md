# Coding Practice Skill

When writing code, follow these steps:

## Coding Practice checklist

1. **Acute**: Only change what is necessary to fix the issue, do not rephrase, reformat or alter any piece of code other than what is necessary to fulfill the task.
2. **Be uncreative**: Do not follow your own intuition, follow the instructions closely and the existing code style.
3. **Ask questions**: If there is any ambiguity in the instructions, ask for clarification.
4. **Simplicity**: Always opt for the simplest solution that fulfills the task, do not over-engineer.

## How to write code

- Be concise and to the point, follow the instructions closely.
- Do not over-engineer, follow the simplest solution that fulfills the task.
- Solve problems in a simple manner, always relying on the user as the source of truth.
